Features

Built for links that matter.

Every link you create is a small piece of infrastructure. Shorthand treats it that way — reliable, measured, and easy to hand off.

Custom back-halves

Replace the random string with something readable, like short.hn/q4-launch, so the link explains itself.

Click analytics

See clicks by time, location, and referrer as they happen — no dashboard hunting required.

QR codes

Every short link comes with a matching QR code, ready to drop into print or packaging.

Branded domains

Point your own domain at Shorthand so every link carries your name instead of ours.

UTM builder

Attach campaign parameters while you shorten, so attribution is correct from the first click.

REST API

Create, tag, and retire links programmatically. Rate limits scale with your plan, not your patience.

Process

Three steps, in order.

01

Paste your link

Drop in any URL — Shorthand validates it and checks for an existing short link before creating a new one.

02

Customize it, if you like

Set a memorable back-half, add UTM tags, or leave the defaults — the link works either way.

03

Share and track

Send the link anywhere. Clicks start populating your analytics the moment the first person lands.

For developers

An API that reads like the docs.

Generate short links from your own systems — signup flows, CI pipelines, or a cron job that never sleeps.

  • One authenticated POST request, one short link back.
  • Webhooks fire on every click, in real time.
  • 10,000 requests/min on every paid plan. 
# create a short link
curl -X POST https://api.short.hn/v1/links \
  -H "Authorization: Bearer $TOKEN" \
  -d url="https://example.com/campaign" \
  -d alias="q4-launch"

# response
{
  "short_url": "https://short.hn/q4-launch",
  "clicks": 0,
  "created_at": "2026-08-18T09:12:00Z"
}

FAQ

Questions, answered plainly.

Do short links expire?

No. A link stays live until you retire it — there's no default expiry on any plan.

Can I edit where a link points?

Yes. Update the destination URL any time without changing the short link itself.

Is there a free plan?

Yes — shorten links and see basic click counts at no cost. Upgrade for custom domains and full analytics.
